# Великий Сугроб

Рождественская воксельная игра в браузере: раскапывайте огромный сугроб, находите подарки, собирайте праздник у подножия горы и заботьтесь о своём питомце.

Играть: https://nagornyi32-maker.github.io/velikiy-sugrob/

Нужен современный браузер и интернет (3D-движок Three.js и шрифты загружаются с CDN). Прогресс сохраняется в браузере.
